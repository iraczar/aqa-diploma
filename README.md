UI-тесты (Selenide, JUnit 5) обеих форм покупки, проверка записей в БД (MySQL / PostgreSQL), отчёты Gradle и Allure.

## Что нужно установить заранее
- JDK 17 (подойдёт 11 и выше)
- Google Chrome
- Docker Desktop (запущенный)
- Git
